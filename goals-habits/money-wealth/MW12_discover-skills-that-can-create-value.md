# MW12 - Discover Skills That Can Create Value
**Life Stage:** 8–10 — Young Learner | **Pillar:** Money & Wealth | **Sub-domain:** Earning Power

## Goal
Discover Skills That Can Create Value

**Variable:** Useful skills developed (Unit: No.)
**Target Period:** 12 months

## Goal Challenges
1. Service Delivery Day: Master 1 practical skill (e.g., car detailing, photo sorting) and perform it reliably.
2. Value Creation Log: Complete 3 proactive helper tasks in a month that deliver tangible home convenience.

## Habits

### Habit 1 - Learn new skills
Dedicate 30 minutes every week to learning a practical, real-world skill.

### Habit 2 - Help others
Offer proactive assistance to a family member or neighbor without being prompted.

### Habit 3 - Make simple things
Repair or build a useful household tool, craft, or organization rack.

### Habit 4 - Practice communication
Practice clearly explaining the scope of a chore or project you are completing.

### Habit 5 - Identify value created
Ask the person you assisted for 1 piece of constructive feedback to improve.

## Recommended Learning
Skills to Value Conversion (Turning strengths into helper services, reliable delivery, client trust)
